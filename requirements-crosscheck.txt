# skips loudly when it is absent rather than reporting a pass it did not earn.

# It is kept OUT of requirements.txt on purpose, and not for tidiness. chainladder
# requires numpy 2, while requirements.txt pins numpy==1.26.4 so that
# matplotlib==3.6.2 can render the committed charts byte identically. Installing
# both into one environment upgrades numpy and matplotlib 3.6.2 then fails to
# import at all:
#
#   ImportError: numpy.core.multiarray failed to import
#
# So the cross-check runs in its own environment:
#
#   python3 -m venv .venv-crosscheck
#   .venv-crosscheck/bin/pip install -r requirements-crosscheck.txt pytest
#   .venv-crosscheck/bin/python -m pytest tests/test_reserving_crosscheck.py
#
# Verified against chainladder 0.10.0 on CPython 3.11.
